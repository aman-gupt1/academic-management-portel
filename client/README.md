# Academic Management Portal - Frontend

This directory contains the frontend application for the Academic Management Portal.

## Tech Stack

* React
* Vite
* React Router DOM
* Axios
* Tailwind CSS

## Status

🚧 Frontend development is currently in progress.

Upcoming modules include:

* Authentication
* Dashboard
* Student Management
* Teacher Management
* Class Management
* Attendance Management
* Test Management
* Result Management

## Installation

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
